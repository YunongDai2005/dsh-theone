# Website fonts

Inter and Noto Sans SC obtained from the official Google Fonts CSS API, text-subset to this site's content on 2026-10-19. Actual file signature is TrueType (00010000); files use .ttf and format('truetype'). Weights: 400, 500, 600, 700. CSS-only family aliases avoid collisions with installed versions.

Official license sources:
- https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt
- https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt

Both SIL Open Font License 1.1 notices are included alongside the fonts. No Apple font is distributed. Apple devices resolve -apple-system / BlinkMacSystemFont and PingFang SC before these fonts.

These are page-specific subsets: when adding new copy, regenerate the subsets or verify fallback glyphs. Runtime assets are self-hosted; browsers do not call Google Fonts.

01

还有几个小问题

先了解，再开始。

我需要什么版本？

仓库文档列出的兼容环境为 DSH 0.2.0-rc.2 / 0.2.1-rc.2 与 Node.js 24。安装前请以最新文档为准。

会增加模型用量吗？

会。自动分话题、整理历史会话等功能会使用模型调用，费用取决于你的模型服务和用量。可以在设置中关闭不需要的历史整理。

为什么新版本暂时装不上？

DSH 默认等待 npm 版本发布满 24 小时后安装。可以稍后重试；其他安装方式请参阅仓库指南。安装后未出现入口时，可尝试重启 DSH。

发现问题，去哪里反馈？

可以使用插件「话题工作区」里的「报告问题」，也可以在 GitHub 提交反馈。描述复现步骤时，请先去掉密钥和私人聊天内容。

# 第四步分析口径（读取 test 预测前记录）

- 只读取任务指定的 `product-v1-{open,closed}-{dev,test}-cards-deepseek-v4.1-flash.jsonl`。禁止通配读取 predictions；不读取 step3 文件、模型缓存或凭据。
- dev 用于研究和冻结规则。test 在 `freeze.json` 生成之后只执行一次分析；脚本拒绝覆盖 test 结果，冻结文件包含规则、分析程序和 dev 输入的 SHA-256。旧报告中已出现的 test 总体分数不是本轮全新盲测的证据。
- 初判与终判在基线真实预测形成的同一历史上比较。初判 CLARIFY 按产品 settleUnclear 收尾；CREATE 按新话题处理。只改当前一步，后续历史仍是基线历史，不能冒充更换策略后的完整回放。
- open 已有话题 ID 使用基线全段 Hungarian 映射，仅用于事后计分；不重新拟合替代规则映射。反事实 CREATE 若终判也 CREATE，沿用该新话题的映射；否则按 open 首次任务 / 重复拆分判准计分，并单列。不是替代策略的全轨迹聚类准确率。
- 准确率分母沿用评分器：排除 ambiguous 和 gold.thread=null。污染指 wrong_existing / merged_new；加权伤害沿用 0/1/3 代价，按每百条计。歧义和一次性提问另报。
- 95% 区间采用种子 20261101、10,000 次整段对话配对 bootstrap，抽中一段即带入全段计数；不把消息视为独立样本。open/closed、dev/test 分开。稀疏组和零事件区间不代表未知人群风险为零。
- 候选按真实 candidateIds 评价 K=16 上限的集合召回；数组是目录顺序而非相似度排名，不伪报 Recall@1/4/8。分母先分首次任务、正确话题不在目录、正确话题已在目录。短句为 trim 后不超过 16 个 Unicode 字符；同域为任务有同 domain 伙伴；长期返回代理为距离上次该任务至少 10 条中间消息，非跨日证据。目录桶固定 0、1–4、5–8、9–16、>16。
- 新触发器只能删除已记录的复核，不编造未调用模型的结果。运行时输入限候选数、初判动作和已有独有证据；不使用 gold、style、ambiguous、最终答案或模型理由中的标签。
- 明确绑定快路仅接受可解析、可信且仍有效的显式回复对象、指定宿主待答请求、或同一运行轮次 steering；缺元数据即弃权。最近话题、问号形式或单个待答问题不构成绑定。语料没有这些事件时，接管样本数为 0，不能宣称质量不降。
- 门槛固定：准确率差下界 >= -0.5 pp，污染差上界 <= +0.2 pp；额外保守检查加权伤害/100 差上界 <= +0.2。减少污染需上界 < 0。没有匹配快路样本、反事实历史或足够覆盖时不改实际路由；离线影子不等于上线验收。
- 费用使用仓库统一比较价格：未缓存输入 0.30、缓存命中 0.006、输出 1.20 USD/百万 token，卡片和辅助调用算入总量。不是 OpenCode Go 的账单或当前报价。延迟为记录的调用耗时及其串行可避免部分，不宣称端到端实测提速。

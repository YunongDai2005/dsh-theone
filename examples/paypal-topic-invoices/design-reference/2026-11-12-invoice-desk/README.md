# Merged Invoice Desk interface — November 12, 2026

This is the active visual baseline after the user requested merging the new frontend with the completed Codex backend repairs. `manifest.json` records the exact hash of the app's `index.html`, and the backend verification checks that baseline.

The interface provides project tabs, a conversation with routing receipts, selected invoice revisions, manual edits, project correction, local discard, explicit draft approval, activity history and routing metrics. The desktop view places the conversation beside the invoice document. Dark mode retains a white invoice document. Mobile uses a keyboard-accessible review drawer.

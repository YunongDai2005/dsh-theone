# 任务移交、路由降级与错误传递修复验收

2026-11-08。基于 `cfb77401c3fe89674e21c4729cb7a3a47655feac`，修复分支为 `codex/fix-worker-handoff-errors`。

## 修复结果

- **移交收尾**：保留基线已有的旧工具拦截和串行交接，在移交成功后将原 WorkerRun 标为 `superseded`。当前工具批次的结果正常提交，在下一次 `agent/pre-step` 结束旧轮次，不再请求模型。新话题仍等待旧 Worker 完全结束后启动。未成功启动目标时不会提前标记旧任务已移交。
- **路由不可用**：仍允许普通回答、读取和明确的规则路由。规则无法确定归属时，将确认要求保留到实际工具执行阶段；首次改动前询问当前话题或新话题，有候选时也提供其他话题。未回答、无效回答、无确认界面时阻止改动；后续工具尝试不会再次弹问。此情况下移交失败也不会自动授权原话题执行。超时单独记录为 `ROUTER_TIMEOUT`，原有 30 秒总预算不变。
- **错误传递**：主聊天接收 Worker 的具体错误信息、错误码、HTTP 状态、请求标识及重试等待信息。错误文本脱敏并限长；已有成功的改动工具结果时提示结果已保留、继续前检查现状。主聊天的镜像不会重复调用失败的 Worker。取消与移交不被改写成上游请求错误。
